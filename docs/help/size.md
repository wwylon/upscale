# Size

On the **Scale** tab, choose how large the result should be:

- **Scale** — multiply width and height (2×, 4×, 8×, or custom).
- **Long edge** — set the longest side in pixels; the other side follows aspect ratio.
- **Width × height** — exact size with locked aspect ratio.

The panel always shows output pixels, megapixels, and how many 4× model passes will run. Print size in cm and inches is shown at 72, 150, 300, and 600 DPI.
