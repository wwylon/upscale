# Output

Formats: Auto (PNG, or TIFF above 20,000 px), PNG, JPEG, EXIF-JPEG (keeps metadata), WebP, TIFF, BMP, TGA, JPEG 2000, PSD/PSB (flattened composite only). Set JPEG/WebP/JP2 quality and TIFF compression (LZW, Deflate, Zstd, JPEG, or none).

Downloads use a name such as `{stem}_{scale}x.{ext}`.
