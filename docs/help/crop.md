# Test on a crop

Use the **Scale | Test** tabs. On **Test**, choose crop size (32–256 px), place the region on the image (or **Auto-pick detailed area**), and select **models** and/or **classical scalers** to compare. The crop stays marked on the source while results load.

**Find best model** (the primary Run action in Test) runs those variants. Comparison includes an **Original** tile; drag any tile to pan all together, scroll a tile to zoom. **Use this model** (or algorithm) applies the winner and returns to **Scale** for the full image.
