# Wynik

Formaty: Auto (PNG lub TIFF powyżej 20 000 px), PNG, JPEG, EXIF-JPEG (z metadanymi), WebP, TIFF, BMP, TGA, JPEG 2000, PSD/PSB (tylko spłaszczony obraz). Ustaw jakość JPEG/WebP/JP2 oraz kompresję TIFF (LZW, Deflate, Zstd, JPEG lub brak).

Pobrania używają nazwy w stylu `{stem}_{scale}x.{ext}`.
