# Paczka

Dodaj wiele obrazów przez upuszczenie lub wybór. Jedne ustawienia obejmują wszystkie (skala wspólna; dłuższy bok / Szer.×Wys. per obraz). Pasek pokazuje miniatury i postęp. Wyniki pobierasz osobno lub jako zip.

Paczka używa ustawień karty **Scale** (model/metoda klasyczna i filtry). Najpierw użyj **Test** na jednym obrazie, jeśli chcesz porównać modele.
