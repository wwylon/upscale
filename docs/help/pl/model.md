# Model

Na karcie **Scale** wybierz **Model neuronowy** lub **Klasyczny** (Lanczos, algorytmy papierowe albo wektoryzację). Wbudowane modele neuronowe obejmują zdjęcia, anime, odszumianie i szybki SPAN.

Otwórz **Bibliotekę modeli** (link **Modele** w nagłówku, przycisk Method albo Ustawienia), aby zmienić nazwę, opis, ukryć modele na listach (wagi zostają na dysku), pobrać brakujące wagi albo dodać zewnętrzne wagi przez URL, plik lub ścieżkę (preferuj `.safetensors`). Siła odszumiania dotyczy modelu wdn. Modele niepobrane lub z błędem wczytania są oznaczone; nagłówek pokazuje, ile wymaga uwagi.
