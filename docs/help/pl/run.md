# Uruchom

Na karcie **Scale** przycisk **Powiększ** startuje zadanie. Na karcie **Test** ten sam przycisk to **Znajdź najlepszy model** i uruchamia wybrane warianty porównania.

**Wstrzymaj** / **Wznów** między kafelkami zachowuje postęp. **Anuluj** odrzuca częściowy wynik. Jeśli poprzednie zadanie zostawiło punkt kontrolny, **Wznów przerwane** kontynuuje od zapisanego przebiegu. Podglądy etapów pojawiają się na pasku filmowym po każdym przebiegu modelu.
