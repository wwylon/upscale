# Ustawienia

Motyw (Jasny, Ciemny, Systemowy), rozmiar tekstu (Normalny, Większy, Największy) oraz język (angielski i polski; inne wkrótce). Preferencje zapisują się na tym urządzeniu.

Przełączenie **Widok prosty** / **Widok zaawansowany** jest zapamiętywane przy kolejnej wizycie (ciastko + pamięć lokalna).
